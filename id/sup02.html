Jarum api dan terapi cermin dengan sarung tangan robotik: 110 orang dianalisis selama empat minggu

Tentang makalah

火针联合机器人手套镜像疗法对脑卒中后手及上肢功能障碍影响

张伟、黄文婷、崔晓阳、郑婵娟、陈焱强

亚太传统医药, 2024;20(9):73–78

DOI: 10.11954/ytctyy.202409014

Lihat sumber

Kartu artikel ini tidak menampilkan gambar dari makalah.

Sebanyak 113 orang dialokasikan menggunakan tabel angka acak. Tiga orang keluar dan 110 orang dianalisis. Kedua kelompok menerima rehabilitasi biasa dan terapi cermin dengan sarung tangan robotik. Kelompok observasi juga menerima terapi jarum api. Setelah empat minggu, kelompok tersebut memperoleh hasil lebih tinggi pada beberapa ukuran. Perbandingan ini menilai penambahan jarum api pada program yang sama; hasilnya tidak menetapkan efek sarung tangan secara terpisah.

Latar belakang

Cara kerja perangkat dalam penelitian ini masih perlu diverifikasi melalui teks lengkap. Jarum api merupakan intervensi tambahan; pengaturan pelaksanaannya perlu diperiksa dalam teks lengkap. Ketika kedua kelompok menerima terapi cermin dengan sarung tangan robotik, perbandingan antarkelompok menilai intervensi tambahan, bukan sarung tangan terhadap program yang sama sekali tidak menggunakannya.

Pertanyaan pertama dalam desain ini adalah apakah kelompok kontrol sudah menggunakan perangkat tersebut. Ya. Karena itu, kesimpulan membahas kombinasi intervensi.

Latihan tangan dan anggota gerak atas setelah stroke sering dilakukan bersamaan dengan pengobatan, rehabilitasi biasa, dan satu program tangan. Ketika kedua kelompok menerima terapi cermin dengan sarung tangan robotik, perbandingan antarkelompok menjawab apa yang ditambahkan oleh intervensi ekstra. Perbandingan itu tidak menilai sarung tangan terhadap program yang tidak menggunakannya. Jarum api merupakan intervensi tambahan, sehingga yang dibahas adalah kombinasinya.

Desain penelitian

Perbandingan ini adalah sarung tangan ditambah jarum api dengan sarung tangan, bukan sarung tangan dengan program tanpa intervensi.

Sampel dan jadwal

Dari 113 orang yang dialokasikan, tiga mengundurkan diri. Sebanyak 55 orang per kelompok, total 110 orang, dianalisis. Abstrak melaporkan penilaian setelah empat minggu.

Temuan utama

Abstrak jurnal melaporkan bahwa setelah empat minggu kedua kelompok membaik pada torsi puncak, daya rata-rata, kerja total, skor Fugl-Meyer tangan, dan indeks Barthel yang dimodifikasi, sedangkan nilai akar kuadrat rata-rata menurun. Kelompok observasi dilaporkan memiliki hasil lebih tinggi pada ukuran-ukuran pertama tersebut dan nilai akar kuadrat rata-rata lebih rendah daripada kelompok kontrol. Penulis melaporkan tidak ada perubahan yang jelas pada rasio ko-kontraksi. Nilai terperinci perlu diperiksa dalam teks lengkap.

Apa yang ditambahkan penelitian ini

Abstrak jurnal menjelaskan program cermin dengan sarung tangan sebagai bagian dari rangkaian intervensi gabungan. Karena kedua kelompok menggunakan sarung tangan, perbandingan ini tidak menetapkan bahwa sarung tangan saja lebih baik daripada kontrol. Kelompok observasi juga menerima jarum api.

Jika suatu layanan menjadwalkan latihan cermin dengan sarung tangan dan terapi lain pada minggu yang sama, catatan perlu menyebutkan apakah kedua kelompok menggunakan sarung tangan. Abstrak melaporkan bahwa, ketika kedua kelompok menerima terapi cermin dengan sarung tangan robotik, kelompok yang ditambah jarum api memiliki hasil lebih tinggi pada beberapa ukuran setelah empat minggu. Perbedaan ini tidak dapat ditulis sebagai efek sarung tangan saja; tindak lanjut jangka lebih panjang perlu diperiksa dalam teks lengkap.
